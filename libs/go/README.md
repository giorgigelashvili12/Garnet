# Go Shared Libraries

This directory contains shared Go modules, reusable utilities, domain primitives, and common packages used across Go microservices.

---

## Subdirectories

- **`GoCommon/`**: Structured logging wrappers, standard error handling types, context propagation, and event publishing interfaces.
- **`ChatDomain/`**: Shared chat primitives, message contracts, WebSocket payload schemas, and room state types.
