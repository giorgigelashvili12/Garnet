# TypeScript Shared Libraries & Toolkit

This directory contains shared TypeScript packages, UI design system components, API SDK client libraries, and global ambient type definitions.

---

## Subdirectories

- **`api-client/`**: Shared HTTP API client wrapper SDK for frontend apps and microservice-to-microservice communication.
- **`ui-kit/`**: Garnet UI component library, design system tokens, themes, and shared React/Vue components.
- **`@types/`**: Ambient TypeScript interfaces, global entity models, and type definitions.
